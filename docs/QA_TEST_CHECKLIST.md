# 케토끼 이모티콘 메이커 QA 테스트 체크리스트

## 1. 테스트 목적

케토끼 이모티콘 메이커의 주요 기능이 정상적으로 동작하는지 확인하고,
사용자가 실제로 이모티콘 제출용 파일을 만들 수 있는지 검증한다.

---

## 2. 테스트 환경

- Frontend: React + Vite
- Backend: Spring Boot
- Database: MySQL
- Browser: Chrome
- Local URL: http://localhost:5173
- Backend URL: http://localhost:8080

## 4. 공통 기능 테스트

| 테스트 항목        | 기대 결과                                            | 상태 |
| ------------------ | ---------------------------------------------------- | ---- |
| 프로젝트 생성      | 프로젝트 번호가 생성된다                             | 성공 |
| 이미지 업로드      | 선택한 이미지가 업로드 결과에 표시된다               | 성공 |
| 이미지 순서 변경   | 앞으로/뒤로 버튼으로 순서가 변경된다                 | 성공 |
| 이미지 개별 삭제   | 선택한 이미지만 삭제되고 뒤 이미지가 앞으로 당겨진다 | 성공 |
| 전체 초기화        | 선택 이미지와 결과 상태가 초기화된다                 | 성공 |

| 변환 결과 미리보기 | 변환된 이미지가 화면에 표시된다                      | 성공 |
| 대표 이미지 생성   | main.png 또는 대표 이미지가 생성된다                 | 성공 |
| 검수 결과 표시     | 성공/실패 항목이 화면에 표시된다                     | 성공 |
| ZIP 다운로드       | 변환 파일이 ZIP으로 다운로드된다                     | 성공 |

## 6. 이번에 발견하고 수정한 오류

### 1) 파일 자동 삭제 시간이 너무 짧은 문제

- 기존 설정: 1분 후 자동 삭제
- 문제: 테스트 중 원본 이미지가 삭제되어 변환 실패 가능
- 수정: 60분 보관, 10분마다 삭제 검사

```properties
file.cleanup.expire-minutes=60
file.cleanup.interval-millis=600000
```
